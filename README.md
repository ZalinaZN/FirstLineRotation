# FirstLineRotation
Программа вращения отрезка 
Win32-приложение, вращающее отрезок P1Р2 вокруг неподвижной точки P1.
Вращение имитируется перерисовкой отрезка через малые промежутки времени ∆ t = 23мс на малый угол ∆ φ = 1°.
Перерисовка изображения происходит с использованием однородных координат, матриц переноса и поворота в WM_TIMER.
Матрица формируется в WM_CREATE. Кнопка Rotation запускает таймер, а кнопка Cancel выключает таймер при выходе.
Текущее положение отрезка вычисляется по формуле:
P2'' = P2' · T(-x1,-y1) · R(Δφ) · T(x1,y1)
В программе используются структуры Vector, Matrix и процедуры умножения вектора на матрицу и матрицы на матрицу.
